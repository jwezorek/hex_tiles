This project explores a substitution system on colored hexagonal tiles that appears to generate an aperiodic tiling. The goal is to write software that can derive finite local matching rules from the substitution rules, ideally producing a recreational-math style aperiodic tile set and visualizations.

Core idea

Start with a finite set of colored hexagonal prototiles and substitution/inflation rules. Repeated inflation generates large nonperiodic patches. The desired local matching rules should force any legal tiling to have the same infinite substitution hierarchy, which would imply aperiodicity.

The main concepts are:

Substitution tiling: each tile type inflates into a finite patch of smaller tiles.

Supertile: a patch produced by inflating a single tile.

Recognition / recognizability: the ability to uniquely recover parent supertiles from a tiling of smaller tiles.

Collared tile: a tile whose type includes a finite-radius neighborhood around it.

Forcing the border: decorating or collaring tiles enough that substituted supertiles determine their surrounding boundary context.

Matching rules: local adjacency constraints, usually edge labels or an allowed-neighbor table.

Computational plan

For a fixed collar radius r:

Generate inflated patches from every prototile.

Extract all complete radius-r neighborhoods, also called collars.

Treat each distinct collar as a decorated tile type.

Build local adjacency rules: two collared tiles may be adjacent if and only if their stored radius-r patches agree on the overlapping region.

Test recognizability. Every final small tile generated by the substitution should know its immediate parent role from ancestry data. A collar should map to exactly one parent role.

A parent role includes at least the parent tile type, parent orientation, and child index or position inside the parent substitution patch.

If the same collar occurs with different parent roles, radius r is too small.

Increase r or add more decorations until parent recognition is unique.

Stabilizing the collar set

A large finite inflation may miss collars that occur deeper in the tiling. To reduce this risk:

Generate from every prototile, not just one seed tile.

Ignore artificial outer-boundary neighborhoods.

Compare collar sets across increasing inflation depths.

Preferably iterate collar closure:

Start with discovered radius-r collars.

Substitute every tile in each collar patch.

Extract all complete radius-r collars from the substituted patch.

Repeat until no new collars appear.

At a fixed point, the collar set is closed under substitution.

Recognition test

For each tile occurrence in generated legal patches, compute its radius-r collar signature and its immediate parent role.

Build a mapping from collar signature to parent role.

If any collar maps to two different roles, the collar radius or decorations do not force recognition.

After this passes, also check adjacency coherence.

If two adjacent collared tiles claim to be children of the same parent, their child positions must be adjacent in the known substitution patch.

If they lie across a parent boundary, that boundary contact must occur in legal substituted samples.

Edge matching rules

The brute-force local rule is:

Adjacent collared tiles are allowed only if their stored neighborhoods overlap consistently.

This can be represented as an allowed-neighbor table:

allowed_neighbors[tile_id][direction] gives the list of tile IDs that may appear across that edge.

Later, this table may be converted into explicit edge labels, arrows, colors, or other markings.

Expected result

The first working matching-rule set may be large and ugly: one decorated hexagon for each legal collar. That is normal.

Afterward, try to simplify by merging collared tile types with identical matching behavior, removing unnecessary collar information, compressing edge labels, combining always-adjacent hexagons into larger polyhex tiles, and finding simple visual markings that still force the hierarchy.

Project goals

The project is best framed as recreational mathematics, computational tiling, and generative art rather than as a novel publishable mathematical discovery by default.

A good outcome would be code that generates substitution patches, extracts collars, derives matching rules, tests recognizability, visualizes hierarchy and supertile boundaries, and supports a clear writeup explaining how local rules force the substitution hierarchy and hence aperiodicity.
